# Cursor Spec Kit Adapter

Cursor should consume the curated Spec Kit workflows as skills under
`.cursor/skills/speckit-*`.

Recommended invocation:

- `speckit-constitution`
- `speckit-specify`
- `speckit-clarify`
- `speckit-plan`
- `speckit-tasks`
- `speckit-analyze`
- `speckit-checklist`
- `speckit-implement`
- `speckit-taskstoissues`

Keep Cursor rules lightweight and point back to ECC canonical skills.
