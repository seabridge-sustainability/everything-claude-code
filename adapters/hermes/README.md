# Hermes Agent Spec Kit Adapter

Hermes Agent should treat Spec Kit as AGENTS.md callable workflow sections if it
does not support native slash commands.

Supported names:

- `speckit-constitution`
- `speckit-specify`
- `speckit-clarify`
- `speckit-plan`
- `speckit-tasks`
- `speckit-analyze`
- `speckit-checklist`
- `speckit-implement`
- `speckit-taskstoissues`

The workflow must load canonical ECC skills and preserve SeaBridgeAI approval
gates.
