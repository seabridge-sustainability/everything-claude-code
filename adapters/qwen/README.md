# Qwen Spec Kit Adapter

Qwen Code can consume Spec Kit as command prompts or skill-like workflow files.
Use these command names:

- `/speckit.constitution`
- `/speckit.specify`
- `/speckit.clarify`
- `/speckit.plan`
- `/speckit.tasks`
- `/speckit.analyze`
- `/speckit.checklist`
- `/speckit.implement`
- `/speckit.taskstoissues`

For installations that use `.qwen/skills`, copy wrapper files only and point
back to ECC.
