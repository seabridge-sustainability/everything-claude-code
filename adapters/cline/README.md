# Cline Spec Kit Adapter

Cline should use Spec Kit through prompt/workflow references rather than copied
behavior. Supported names:

- `speckit-constitution`
- `speckit-specify`
- `speckit-clarify`
- `speckit-plan`
- `speckit-tasks`
- `speckit-analyze`
- `speckit-checklist`
- `speckit-implement`
- `speckit-taskstoissues`

If a slash-command layer is available, map `/speckit.<command>` to the matching
canonical ECC skill.
