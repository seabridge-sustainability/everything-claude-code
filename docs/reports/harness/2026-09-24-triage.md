## 2. Per-rule triage

TP means a real, actionable defect, not just a literal match of the pattern.

### frontend.button-accessibility-review: 423 findings, sample 15, estimated TP about 20% (3/15)

The sample was seeded-random across the whole set. Across all 426 button-rule findings:
- 162 are `<Button` components.
- 361 have `{expr}` children that the text regex cannot see.

- **TP** `manageesg-frontend/src/components/views/lca/GoalScopeView.tsx:1025`: a `<button>` whose only child is `<X size={14} />`, with no aria-label. It is really icon-only, but it landed in the low-confidence rule. The icon pattern `[A-Z][A-Za-z0-9]*(…|X|Plus|…)` needs at least one character before the suffix, so a bare `<X>` or `<Plus>` never counts as an icon.
- **TP** `.../data-building/view-usage/AddUtilityBillWizard.tsx:1279` (`<X>` only) and `.../climate-risk/ClimateOpportunitiesUploadFileDialog.tsx:535` (`<Button>` with `<Plus size={16}/>` only): same gap.
- **Noise** `.../climate-risk/TransitionRisk.tsx:1098`: `<Button>{isDeleting ? "Deleting..." : "Delete"}</Button>`. The visible-text regex needs `>letter`, so any `{…}` child fails. Same for `companyDetailsPage.tsx:523`, `addPolicyPopup.tsx:663` and `InitiativeCommandRecovery.tsx:86`.
- **Noise** `.../initiatives/DesignNewInitiativeSection.tsx:210`: the text "Property level" sits on line +8 and `</button>` on line +9, outside the 9-line window. `ProcurementPage.tsx:280` fails differently: its text follows `/>}`, not `>`. `ClimateMitigationPlanSummary.tsx:324` fails because its text is longer than 120 characters.

### frontend.raw-fetch-boundary: 11 findings, sample 11/11, TP about 36% (4/11)

- **TP** `manageesg-frontend/src/app/api/v1/[...path]/route.ts:65`: the main backend proxy. Its `fetch` has no timeout and does not forward `request.signal`, so a browser abort never cancels the upstream request and a hung backend holds the socket. This is consistent with the ECONNRESET/503 errors seen under load.
- **TP** `src/app/api/auth/session/route.ts:38`: the Cognito JWKS fetch on the login path has no timeout. A slow IdP stalls every login until the socket times out.
- **TP** `src/components/views/nature-risk/MapBox.tsx:278`: the browser sends the tenant's property address to `nominatim.openstreetmap.org`. That leaks data to a third party, breaks Nominatim's usage policy, and has no timeout.
- **TP, low** `src/components/exports/ExportPptxButton.tsx:55`: the share-viewer PPTX download has no timeout.
- **Noise-ish, by design:** `AiInsightAssistant.tsx:645/888`, `LCAAssistant.tsx:108`, `OpenWorkSessionStream.tsx:26`, `SimulationChatPanel.tsx:68`, `SimulationProgressPanel.tsx:78` and `reports/plan/page.tsx:69`. These are SSE streams to the same-origin proxy (`API_STREAM_BASE_URL=''` in the browser), with auth from an httpOnly SameSite=strict cookie. Most use an AbortController. The typed client does not stream, so these are policy exceptions, not bugs.

## 4. Rule-tightening recommendations (suggestions only)

1. **Baseline fingerprint drift.** Line numbers in fingerprints produced 261 false "new" findings.
   - Fingerprint on `rule|relative-file|normalised line text` (or text plus an occurrence index).
   - Store paths relative to the repo root, not `C:/Users/...`.
2. **Exclude evidence trees.** Add `\\docs\\reports\\` (and `\\evidence\\`) to `$backendExcludes`. That removes 279 findings, 37% of the scan.
3. **Button case-sensitivity.** Use `-cmatch '<button\b'` for native buttons. If `<Button>` should be checked, handle it separately and allow `{…}` children.
4. **Visible-text heuristic.**
   - Count `>…{expr}…</button>` and text after `/>}` as having an accessible name.
   - Scan to the matching `</button>` rather than a fixed 9 lines.
   - Drop the 120-character cap.
   - Fix the icon pattern so bare `<X>`, `<Plus>`, `<Check>` count: `<(Icon|[A-Z][A-Za-z0-9]*?(Icon|Chevron|…))\b` with a lazy prefix, or list the bare names.
   - With these changes most of the ~60 to 80 real icon-only buttons would move into the medium icon-button rule, and the low rule would become far less noisy.
5. **route-auth-boundary has false negatives.** `$isPublicRoute` matches `status` anywhere in the 25-line window, so any handler using `status.HTTP_…`, `status_code=` or `{"status": …}` is silently exempt.
   - Match only the route path from `Get-RoutePath`, not the body window.
   - Treat in-handler guards (`_require_api_key`, `_get_validated_token*`, `_portal_context`, `Header(` + `verify_`) as recognised auth, or require a `# harness: public-route <reason>` marker. The existing marker at `openseabri_routes.py:3074` is currently ignored.
   - Fix the allowlist: `share_viewer` should be `^/\{token\}/`, and the openseabri entry should target `app/api/openseabri_routes\.py$`.
6. **retry-bounds.**
   - Skip comment lines, as the timeout rules already do.
   - Skip `while True:` when the next ~15 lines contain `break`, `return`, `raise`, `StopIteration`, or `await asyncio.sleep` inside a task that is `create_task`'d and cancelled.
   - Otherwise the rule stays at 0% TP.
7. **subprocess-timeout.** Once docs/ is excluded, give `aws|gcloud|curl|kubectl` and `requests`/`httpx` a higher severity than local `git`/`ruff` calls.
8. **raw-fetch-boundary.** Allow `src/app/api/**` route handlers (server proxies) and require an explicit `signal`/`AbortSignal.timeout` there instead. Flag third-party hosts (`https://` literals) as medium.
