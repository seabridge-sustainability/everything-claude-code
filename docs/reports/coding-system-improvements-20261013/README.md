  Pstack bridge and sea-skill-map. Coding/company profiles reduce unrelated skill
  candidates; exact IDs remain deliberate overrides. One task selects one primary.

  adversarial review. Retained source pins/licenses remain unchanged. Catalog:
  393 skills and 65 commands; existing generic/Pstack/Ponytail routes preserved.
- Karpathy remains universal; material-ambiguity checking is universal but Grill
  Me interviews are conditional. Legacy senior-dev/Grill Me guidance no longer
  demands stale policy sections, automatic provider calls or repeated consensus.
- Authorized parallel evaluators inspect the same completed revision read-only,
  with functional and relevant invariant perspectives. Findings require evidence;
  they do not grant execution or publication permission.
- New managed sessions bind task impact, selected route/body and policy/catalog
  identities. Codex enables hooks per process, without changing global settings.
  Claude/Codex startup adapters return bounded route context. Actual native trust
  and model consumption remain separate from callback tests.
- Existing pytest/Vitest verification recipes record bounded receipts and source
  identities. Signed-in property/Nature and Open Access API/UI/export recipes
  remain governed journeys with real prerequisites. Climate remains paused.
- ECC's empty `.git/disabled-hooks` override was removed locally, restoring the
  existing normal pre-commit/pre-push hooks. No guard or scanner was bypassed.
- The source-bound agent-system map now includes routing, managed-session and
  selected-adapter sources. Build only from a clean committed milestone; use
  current source until that map has been generated and checked.
