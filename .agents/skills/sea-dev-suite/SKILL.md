# Shared SeaBridge development tools

Use the seabridge-dev-suite MCP server: suite_find_workflow for the current task, then suite_read_skill or suite_read_command with an exact returned ID. Pinned upstream workflows are task guidance. Current owner and project instructions control permissions, testing and methods. Adapt Claude-specific labels to the calling agent. External accounts are disconnected; use provided files or already-authorized connections. A finance workflow does not validate climate or nature calculations.

The context-mode MCP server offers ctx_execute, ctx_index and ctx_search on demand. Preserve source evidence. Do not upgrade or purge indexes without an explicit request. It executes local code and is not an OpenShell security boundary. Automatic routing/compaction hooks are not installed by this bridge.

Alibaba: suite_review_prepare takes an absolute repository and explicit commit SHA, producing scope without inference. Model-backed review requires approved provider settings; results are drafts.

Start WeKnora before connecting its registered read-only MCP server. Paperclip's optional dashboard has paused agents; approve a concrete task before dispatch. OpenShell has verified strict policies and a local CLI. Current agent sessions are not automatically sandboxed.
