# ponytail-help

Use sea-ponytail and PONYTAIL_ECC_GUIDE.md. Six workflows: implementation lens, review, audit, debt, benchmark provenance and help. Lite/full/ultra/off are selected in the current conversation without global flag files. MCP offers find/read/debt; CLI is the fallback. Follow current project policy, one active goal and one primary workflow; preserve running agents.
