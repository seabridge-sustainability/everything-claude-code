# create-verification-skill

Use sea-verify-seabridge and the existing verification-loop. Interview source and existing harnesses. Define prerequisites, doctor, drive, assertions, evidence and cleanup. Extend an existing test or recipe before adding a harness. Prove the recipe against its declared target; unexecuted recipes remain configured-unverified. Reuse primary listeners and approved test data; no automatic seeding, migrations or replacement servers.

Use the current project instructions and active ECC goal. Upstream is pinned at 7845807642f9ef234a0ec5b4067fa3f11fd92a85; its defaults do not grant scope, tool access or approval.
