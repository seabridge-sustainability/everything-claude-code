# Sustainability Data Quality Checklist

- [ ] Source known.
- [ ] Unit known.
- [ ] Geography known where relevant.
- [ ] Timeframe/year/scenario known where relevant.
- [ ] Boundary/scope known where relevant.
- [ ] Confidence/provenance known.
- [ ] Assumptions visible.
- [ ] Missing data visible.
- [ ] Verified/provisional/demo status visible.
