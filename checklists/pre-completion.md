# Pre-Completion Checklist

Canonical source: `skills/sea-verification-before-completion/SKILL.md` and the
Self-Verification Loop in ECC `AGENTS_SYSTEM.md` — if this list and those
sources ever disagree, they win.

- [ ] User request fully addressed.
- [ ] No requirement silently dropped.
- [ ] Plan/assumptions and done criteria were stated before edits.
- [ ] Relevant tests were written or updated when practical.
- [ ] Old behavior produced the intended failing test when practical, or skip reason is documented.
- [ ] Focused tests/checks pass after the fix.
- [ ] Focused tests/checks run or clearly skipped with reason.
- [ ] Broader tests/checks run when risk warrants, or skip reason is documented.
- [ ] Self-review completed.
- [ ] Data integrity/domain/security risks checked.
- [ ] Files changed and remaining caveats documented.
- [ ] No automatic commit/push unless requested.
- [ ] Completion is not claimed from code changes alone.
