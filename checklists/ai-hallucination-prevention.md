# AI Hallucination Prevention Checklist

- [ ] Allowed data sources listed.
- [ ] Missing data returns unavailable/missing, not fabricated.
- [ ] No invented emissions factors, LCA values, risk scores, utility data, supplier data, target values, due-diligence findings, or financial values.
- [ ] Output includes source/provenance/confidence where needed.
- [ ] Draft estimates are opt-in and visibly provisional.
- [ ] Exports do not present draft AI output as verified.
- [ ] Tests cover missing-source behavior.
