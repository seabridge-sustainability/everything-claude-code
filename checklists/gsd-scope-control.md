# GSD Scope Control Checklist

- [ ] Original user request is restated.
- [ ] Every requirement is represented, explicitly deferred, or explicitly out of scope.
- [ ] No requirement was silently dropped.
- [ ] Backend/API impacts are listed.
- [ ] Frontend/UI impacts are listed.
- [ ] AI/model impacts are listed.
- [ ] Sustainability-domain impacts are listed.
- [ ] Security impacts are listed.
- [ ] Cross-repo contracts are listed.
- [ ] No invented sustainability data is allowed.
- [ ] No backend/frontend mismatch is accepted as complete.
