# Frontend UI/UX Checklist

- [ ] Route and navigation entry verified.
- [ ] Endpoint caller verified.
- [ ] UI shows only available data.
- [ ] No dead buttons or fake actions.
- [ ] AI/advisor controls open the expected surface.
- [ ] Charts use space well and update with filters.
- [ ] Cards, tables, charts, and summaries agree.
- [ ] Empty/loading/error states are useful.
- [ ] Responsive behavior checked or caveated.
- [ ] Accessibility basics checked.
