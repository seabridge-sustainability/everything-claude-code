# GSD Phase Verification Checklist

- [ ] Phase acceptance criteria are checked.
- [ ] Endpoint registration is verified where relevant.
- [ ] Request/response schema is verified where relevant.
- [ ] Database/source writer and reader are verified where relevant.
- [ ] Auth and tenant isolation are verified where relevant.
- [ ] Frontend route and visible state are verified where relevant.
- [ ] AI output grounding, provenance, and confidence are verified where relevant.
- [ ] Sustainability units, boundaries, scenario, timeframe, and source are verified where relevant.
- [ ] Tests or checks were run fresh.
- [ ] Skipped checks are explained.
- [ ] Remaining risks are recorded.
