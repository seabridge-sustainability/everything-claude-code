# AI Output Verification Workflow

1. Identify prompt, state schema, tools, retrieval, and output parser.
2. List allowed data sources.
3. Ensure missing data produces missing-data output, not fabricated values.
4. Check citations/provenance and provisional labels.
5. Add refusal/edge tests for missing factors, unavailable risk data, unknown suppliers, and unsupported claims.
6. Verify exports do not present draft AI outputs as verified results.
